# 🗂️ Habit Tracker

> Its tracker for real developers, created on the basis of jokes

Трекер привычек прямо в терминале. Добавляй привычки, отмечай выполненные и следи за прогрессом не выходя из консоли.

## Installation

Clone the repository:
git clone https://github.com/requeste/habit-tracker.git
cd habit-tracker
pip install -e .

## Usage

habit add "кодить"    # добавить привычку
habit show                  # показать все привычки
habit done "кодить"   # отметить выполненной
habit delete "кодить" # удалить привычку
habit info                  # информация о проекте

## Requirements

- Python 3.10+
- Windows / macOS / Linux
